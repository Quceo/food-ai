# 🍳 Food AI - Умный генератор рецептов

Консольное приложение на Python, которое использует нейросети для генерации рецептов на основе продуктов, которые уже есть у вас дома. Больше не нужно ломать голову над вопросом «Что приготовить?».

## ✨ Возможности

- **Генерация рецептов:** Предлагает ровно 3 блюда из имеющихся у вас продуктов.
- **Список недостающих продуктов:** Указывает, что нужно докупить для приготовления.
- **Пошаговые инструкции:** Подробно описывает процесс приготовления.
- **Строгий формат JSON:** Нейросеть возвращает данные в структурированном виде (благодаря `response_format`), что гарантирует стабильную работу программы без ошибок парсинга.
- **Гибкая настройка:** Поддержка любых API, совместимых с OpenAI (официальный OpenAI, OpenRouter, локальные модели и др.).

## 🛠️ Технологии

- **Python 3.8+**
- **OpenAI Python SDK**
- **JSON** (для обработки ответов нейросети)

## 🚀 Установка и запуск

Следуйте этим шагам, чтобы запустить проект на своем компьютере:

### 1. Клонирование репозитория

```bash
git clone https://github.com/Quceo/food-ai.git
cd food-ai

### 2. Создание виртуального окружения

Рекомендуется использовать виртуальное окружение, чтобы не засорять основную систему:

**Для Windows:**
```bash
python -m venv .venv
.venv\Scripts\activate
```

**Для Mac/Linux:**
```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Настройка API и модели (ОБЯЗАТЕЛЬНО)

> ⚠️ **Внимание:** Без этого шага программа выдаст ошибку при запуске!

Для работы программы вам понадобится API-ключ от любого провайдера, совместимого с OpenAI (например, OpenAI, OpenRouter, VseGPT и т.д.).

1. **Создайте файл `api_key.txt`** в корневой папке проекта (рядом с `main.py`).
2. Откройте его блокнотом и **вставьте ваш API-ключ** (без кавычек и лишних пробелов). Сохраните файл. 
   *Пример содержимого файла `api_key.txt`:*
   ```text
   sk-or-v1-1234567890abcdef...
   ```
3. Откройте файл **`ai.py`**. Если вы используете не официальный API OpenAI, а сторонний сервис (например, OpenRouter), раскомментируйте параметр `base_url` и укажите адрес вашего провайдера:
   ```python
   return OpenAI(
       base_url="https://openrouter.ai/api/v1", # Укажите URL вашего провайдера (если нужно)
       api_key=api_key
   )
   ```
4. Откройте файл **`prompt.py`** и в строке `model="..."` укажите название модели, которую вы хотите использовать (например, `gpt-4o-mini` или `openai/gpt-4o-mini`).

*🔒 **Важно:** Файл `api_key.txt` добавлен в `.gitignore`, поэтому он никогда не попадет в публичный доступ на GitHub. Никогда не выкладывайте свои ключи в открытые источники!*

### 5. Запуск

```bash
python main.py
```

## 📂 Структура проекта

- `main.py` — основной файл программы (взаимодействие с пользователем и вывод результата).
- `prompt.py` — формирование промпта, выбор модели и отправка запроса к нейросети.
- `ai.py` — настройка подключения к API (чтение ключа, настройка `base_url` и создание клиента).
- `requirements.txt` — список необходимых библиотек.
- `.gitignore` — исключает из Git системные файлы и секреты.
